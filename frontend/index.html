HOW IT WORKS

From a raw budget file to a red flag report in four steps.

Upload

Drop in a federal or state budget file. PDF, XLSX, XLS or CSV.

Scan

Flagly parses every line item and checks it against ten red flag patterns.

Flag

Suspicious items are scored by risk and grouped by flag type.

Report

Export a PDF report with the exact line items, amounts and evidence.

DETECTION ENGINE

Ten red flag categories, built from the patterns auditors look for.

Duplicate Clusters

Same project listed more than once

Budget Splitting

Large contracts broken into smaller pieces

Inflated Amounts

Costs far above market rate

Context Mismatch

Description does not match the ministry

No or Vague Location

Missing or unverifiable project site

Ghost Projects

No evidence of delivery or existence

Mandate Mismatch

Outside the agency legal function

Inflated Projection

Unrealistic revenue or growth forecasts

Zero Rollover

Prior year funds unaccounted for

Composite Duplicate

Split contracts with matching totals
